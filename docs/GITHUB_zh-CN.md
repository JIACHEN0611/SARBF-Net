# GitHub 仓库维护

源码仓库为 [JIACHEN0611/SARBF-Net](https://github.com/JIACHEN0611/SARBF-Net)。源码以解压后的文件夹结构提交，实验资产通过 Release 附件发布，原始数据单独下载。

更新已有仓库见 [GITHUB_UPDATE_zh-CN.md](GITHUB_UPDATE_zh-CN.md)。更新主分支不会改变 v1.0.0 标签和四个资产分卷；无需重复上传大型附件。

源码根目录应直接看到 `README.md`、`run.py`、`model/`、`layers/` 和 `tools/`。不要把源码 ZIP 本身当作仓库源码上传，也不要把整层 `SARBF-Net/` 套到现有根目录下面。提交后检查 README 的相对链接及 Actions 检查结果。

仓库可见性由项目发布安排决定。Private 仓库和附件仅对有访问权限的账户开放。许可证状态见根目录 LICENSE.md。
